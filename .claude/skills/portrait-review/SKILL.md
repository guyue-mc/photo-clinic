# 人物摄影评审标准

## 评分总则（从严、一致）

- 满分标准（多层锁）：构图 3 分 / 光线 4 分 / 后期 3 分 = **无瑕疵 + 有出彩之处**，属于少数顶尖作品（构图 3 分与光线 4 分 ≈ 前 10%）；「只是没毛病」不等于满分——给满分必须在评语中写出该维度超出常规的出彩之处（独特视角、框架式/引导线构图、光效运用、氛围营造等），并填入 exceptional_note 字段；无法给出出彩之处时，构图最高 2.5、光线最高 3.5。良好作品的常规档位为构图 2.5 / 光线 3.5 左右。照片存在重大问题时，其余维度的满分须由复核轮在 full_mark_endorsements 中显式背书（写明出彩之处与已排查项），未背书则由系统自动降 0.5。
- 强制自查：每个维度先逐项对照扣分项自查（构图：水平、前景干扰、裁切、畸变、主体明确性、平衡；光线：光比、过曝死黑、光位立体感、眼神光、光质氛围），实际存在的瑕疵（哪怕轻微）必须写入 deductions；给满分必须在评语中逐项确认「已排查……均无问题」，不得笼统带过。
- 扣分联动：单个轻微扣分点最多扣 0.5 分，每项明显瑕疵至少扣 0.5 分，3 处以上轻微瑕疵至少降 1 分；有扣分点不得给满分。
- 分数与评语一致：评语以正面为主时不得打低分。
- 重大问题：命中重大问题的维度由系统封顶（≤1.0），模型无需自行再压。
- 评审以暴露不足为专业，宁可偏低不可虚高。

## 边界与禁止

- 评审范围：只评估摄影表现（构图、光线、后期、主题表达、模特表现与妆造）；不评价画面内容的道德、法律、价值观，不评论题材本身的喜好。
- 不自创规则：扣分理由必须以本 rubric 各维度扣分项为准，不得自创扣分项或评分标准。
- 不自我豁免：豁免仅限第 0 节明确列出的情形（皮肤本身为非人类色、整体强风格化）；cosplay、角色扮演、氛围、风格化陈述均不构成豁免理由。
- 不输出内部机制：评语与扣分点不得引用内部字段名（skin_report / exempt / whiteness / texture_report / pore_visibility / plastic_level 等）、不得叙述豁免判定或像素检测等内部推理过程，直接陈述结论。
- 输出边界：只输出模板结构与契约字段；不输出 route / 置信度 / usage / 内部报告。
- 建议一致性（焦段，硬规则）：焦段由画面表达的观感决定——张力/压迫/戏剧感 → 广角；唯美/简洁/柔美 → 长焦。先按画面观感确定目标焦段，再看当前焦段是否符合：符合 → 只谈使用问题（前景运用、机位、虚化程度等），不得建议换焦段；不符合 → 建议换用目标焦段并说明原因。对照表条目仅为方向参考，须结合画面意图选用。
- 使用问题与焦段问题分开：广角边缘变形（人脸贴边、边缘拉伸）是**使用问题**——人物未居中所致，通过让人物居中/调整站位解决，不是换焦段的理由；长焦画面的压缩/扁平感属焦段固有特性，不是缺陷。
- 焦段判断谨慎：不得凭「人物贴边/边缘变形」断言广角——贴边变形是人物偏位导致的使用问题，长焦画面同样会出现；除非画面存在强烈的广角透视特征（夸张的近大远小、明显的空间纵深拉伸），否则不得断言「广角」；无法确证焦段时，不提焦段、不据此建议换焦段。
- 表述语言：加分/前提观察等段落用具体画面语言描述实际看到的内容（如「手部前伸与血迹增强了叙事与互动感」「发丝飞扬、姿态抓拍自然」），不得引用 rubric 内部术语（如「生命力四要素」「动态的道具」「不确定的瞬间」等）。

## 0. 重大问题排查（先于评分执行）

正式评分前先排查重大问题；存在任一项时，必须在输出最前面以【重大问题】段落逐条点出（先于【评分】行），再进入板块评分。重大问题命中后，系统会在所属维度上狠狠扣分（该维度得分封顶 1.0，总分按扣后分值重算），模型无需自行压低分数。对上述任一项判定存在不确定（两可、无法确认、可能漏判）时，在 possible_issues 中列出对应方面（如「肤色」「皮肤质感」「曝光」）；确定无疑（无论有或无）则留空数组。该字段仅用于触发一轮复核，不参与点评输出。

1. 人物肤色是否正常合理（第一优先）：是否构成重大问题不由模型直接下结论，改为在 skin_report 中如实报告事实（判定由系统规则执行）：whiteness（肤色发白程度：natural 自然有血色 / pale 偏白发白 / white 惨白无血色；青白、灰白、苍白均归入 pale/white）；exempt（豁免标记：仅当皮肤本身为非人类色（蓝/紫/绿等奇幻种族设定）或整体强风格化（黑白、单色、强滤镜）时为 true；cosplay / 角色扮演、动漫风服装与道具不豁免——扮演者的皮肤仍是人体皮肤，发白不豁免）。报告必须如实基于观察，禁止因担心被判为重大问题而轻报。不发白的色调处理（偏黄、偏青、偏暖、偏冷）按场景判断：与场景光色协调则不算异常（暖景偏暖、冷景偏冷均正常），明显不协调或病态观感（发青发紫、病态蜡黄且脏）列入扣分点或重大问题（按严重程度）。
2. 曝光硬伤：大面积过曝死白或死黑，人物主体无法辨认。
3. 构图硬伤：主体关键部位（头部、面部）被切断，或严重倾斜无支撑。
4. 清晰度：人物面部/眼睛明显失焦、模糊。
5. 畸变比例：人脸或肢体明显畸变、比例严重失调。
6. 后期硬伤：液化失真、色调脏乱、颗粒过度。皮肤质感（磨皮）问题不进重大问题，最多列入对应维度扣分点；如需要，在 texture_report 中如实报告观察事实：pore_visibility（毛孔/肌理可见性：clear 清晰可见 / partial 部分可见 / none 完全不可见）；texture_coverage（可见纹理覆盖范围：most 大部分 >70% / half 约一半 / partial 少部分 / little 几乎无）；plastic_level（塑料/蜡质感程度：none 自然 / slight 轻微光滑 / moderate 中等塑料感 / obvious 明显塑料蜡质 / severe 严重塑料失真）。报告必须如实基于观察。cosplay 与妆造不豁免（妆感是化妆，不等于磨皮）。判为正常（partial 及以上）时须在评语中说明实际观察到的皮肤纹理细节（如鼻翼毛孔、脸颊肌理）及其覆盖范围，禁止以「皮肤光滑」「无塑料感」一笔带过。

轻微瑕疵与可接受的后期处理不算重大问题。

## 一、构图（3分）

### 1. 基础功（1分）

判断点：
- 横平竖直，明显水平线/垂直线不歪斜
- 背景干净简洁，头部不穿线，不杂乱
- 裁切避开关节：脖子、腰、膝盖、手腕等

扣分项：
- 背景杂乱、元素穿头
- 明显歪斜
- 关节处裁切不当

### 2. 视角与焦段（1分）

判断点：
- 视角有变化，避免普通平视
- 仰视、俯视、低机位可增加张力
- 广角人脸尽量居中，避免贴边畸变
- 长焦/人眼焦段构图自由，人物可放三分线、趣味点
- 单张照片景别清晰明确，与视角、构图意图匹配

扣分项：
- 广角人脸贴边变形
- 平视无视角变化
- 景别选择混乱，表达意图不清

### 3. 层次与平衡（1分）

判断点：
- 有前景、中景、背景的层次
- 兴趣点明确，人物放在三分线/中心/对称位置合理
- 倾斜构图有相对平衡，不是无理由歪斜

扣分项：
- 画面平，无前景
- 兴趣点混乱
- 倾斜无支撑，画面散乱

## 二、光线（4分）

### 1. 光比与曝光（1.5分）

判断点：
- 光比合适，高光不过曝，阴影不死黑
- 阴影区域保留微弱光线
- 以人脸曝光为主
- 正常曝光后期空间最大

扣分项：
- 逆光大面积过曝
- 阴影死黑，无细节
- 人脸欠曝或过曝

### 2. 光位与立体感（1.5分）

判断点：
- 侧光：近镜是影子、远镜是光，显瘦
- 顺光：近镜是光、远镜是影子，显胖；但有斑驳光时好看
- 逆光：有发丝光/轮廓光，找遮挡，不直拍光源
- 顶光：抬头强化轮廓，光影方向自然从上往下（顶光不足、鼻影不明显属正常光影差异，不构成扣分点）
- 有眼神光；眼睛在光里，脸上有斑驳感更好

扣分项：
- 顺光把脸拍平、显胖
- 逆光无轮廓、无遮挡
- 顶光不抬头，鼻影倒冲（仅倒冲扣分；顶光不足、鼻影不明显属正常光影差异，不扣分）
- 无眼神光，眼睛死黑

### 3. 光质与用光逻辑（1分）

判断点：
- 选景即选光，优先选好光位/窗光
- 窗光是巨型柔光箱，但要注意光比
- 斑驳光、遮挡、反光板使用合理
- 影子是模特的一部分，不要全部照亮
- 人造光：灯头架高、尽量离机引闪，面部不要打过多灯

扣分项：
- 光线平淡，无明暗层次
- 灯光影子乱，面部光影脏
- 机顶直打，人物像贴纸，无立体感

## 三、后期（3分）

### 1. 影调与色彩（1.5分）

判断点：
- 高光、阴影层次分明，不发灰
- 黑白模式下依旧好看，影调合格
- 肤色自然、有血色，不发白不惨白，橙色通道处理得当
- 色温准确：肤色是色温的锚点，面部肤色应接近真实人体肤色；全图冷调/蓝绿调时须单独核查肤色是否被带偏（除非是明确且一致的创意风格）
- 有黑白对比、冷暖对比、分离层次

扣分项：
- 强拉阴影导致发灰
- 肤色发白/偏白/惨白（正常肤色不应偏白）、蜡黄（与场景光色不协调的病态黄）或脏，或被环境冷色调带偏、发白发青（色温偏差；与场景光色一致的暖/冷调氛围处理不算）
- 色彩平淡，主体无法从背景中剥离

### 2. 液化与质感（1分）

判断点：
- 液化是微调：眼型、眼神光、脸型中庭/眼位/下庭
- 保留皮肤质感，不塑料磨皮
- 不盲目放大眼睛，不换脸

扣分项：
- 磨皮过度，皮肤塑料感
- 液化失真，五官比例失衡
- 盲目追求"锥子脸""大眼"

### 3. 统一与二次构图（0.5分）

判断点：
- 画面色调统一，无局部突兀
- 二次构图裁切/扩展补救有效
- 颗粒/胶片质感适度，顺光不加颗粒

扣分项：
- 色调不统一，画面局部色彩跳跃
- 颗粒过多，画面脏
- 二次构图无效，未补救前期构图缺陷

## 四、加分/前提项（不计入10分，单独点评）

这些内容不占评分，但会明显影响观感：
- 模特表现力：美或怪，或两者兼具
- 妆造：妆面是否定住，是否适合主题
- 道具/主题：是否主题先行，道具是否加分
- 生命力四要素：飞扬的发丝、灵动的姿态、不确定的瞬间、动态的道具
- 情绪与眼神：眼神是否灵动，有无眼神光，是否避免呆滞
- 引导细节：如"拿叶子看远方"，避免斗鸡眼

## 五、常见问题改进对照表

| 常见问题 | 前期拍摄建议 | 后期修图建议 |
| --- | --- | --- |
| 背景杂乱 | 换机位、用长焦、大光圈、低机位 | 裁切、二次构图、背景压暗/虚化 |
| 光比过大/逆光过曝 | 找遮挡、转侧逆光、用反光板、换拍摄时间 | 降低高光，提升阴影，保留层次 |
| 顺光显胖 | 转侧光/侧逆光，制造斑驳光 | 液化脸部，加强阴影立体感 |
| 广角畸变 | 人物放中间，换长焦或人眼焦段 | 透视矫正、二次构图 |
| 皮肤塑料感 | 正常曝光，不过度依赖后期 | 保留质感，降低磨皮强度 |
| 影调发灰 | 前期控制光比，阴影保留微弱光 | 黑白模式检查，调整曲线/色阶 |
| 色调不统一 | 固定色温，推荐5400K，统一光色 | LR/PS色彩平衡统一 |
| 肤色发白发青/色温偏冷 | 固定色温，以肤色为基准校白平衡 | 色温回调，肤色通道单独校正 |
| 缺少层次 | 加前景，控制光比，选光即选景 | 分离前景/主体/背景，拉开纵深 |
| 眼神呆滞 | 多沟通引导，拍低速连拍抓瞬间 | 后期加强眼神光，但不要凭空乱加 |

## 六、快速评分口诀

构图：横平竖直、广角居中、长焦自由、人眼三分、前景层次。
光线：顺光斑驳、逆光遮挡、侧光显瘦、顶光抬头、光比合适、人脸曝光。
后期：先定影调、再调肤色、液化微调、保留质感、黑白检查、统一色调。

## 输出

交互场景（Claude Code）：按上方「点评输出模板」逐段输出。

展示规则：有重大问题时先输出【重大问题】段落并逐条列出，置于【评分】行之前；无重大问题则省略该段落。点评各段落只写评语，不写子项小分（如「基础功（1/1）」），也不在评语中写扣分点（扣分点统一放 deductions 字段）；【评分】行不显示各部分的满分，只写分值本身与总分；直接输出模板，不加额外标题（如「摄影评审结果」）、不输出 route / 置信度等内部字段。评语与扣分点中禁止叙述内部判定机制：不得写豁免判定推理过程（如「需判断是否豁免」「exempt 应为 false」）、不得引用内部字段名（skin_report / exempt / whiteness / texture_report / pore_visibility 等）、不得说明像素检测，直接陈述结论（如「肤色惨白，缺乏血色，构成重大问题」）。输出时每个点评段落之后另起一行输出扣分点行，格式「扣分点：A、B、C」（deductions 用顿号连接），无扣分点则输出「扣分点：无」。禁止将顶光不足、鼻影不明显列为扣分项。被系统重大扣分的板块，【评分】行展示「板块名 X-Y（重大问题扣分）= Z」（X=原始小计，Y=重大扣分额，Z=实得分），如「后期 1.5-0.5（重大问题扣分）= 1」；未扣分的板块只写分值。

JSON 字段契约（API 服务器，由调用方 schema 强制）：
- total_score: 构图 + 光线 + 后期 之和（0-10）
- dimensions: 三项 [{dimension, score, comment, deductions, exceptional_note}]——构图（满分3）、光线（满分4）、后期（满分3），满分仅用于内部计分；comment 只写评语，不写子项小分、不写扣分点；deductions 为扣分点列表（字符串数组，每条一个扣分点），无扣分点则为空数组 []；exceptional_note 为满分维度的出彩声明（非满分维度留空）
- bonus_notes: 加分/前提项观察（模特表现力、妆造、道具/主题、生命力、情绪眼神、引导细节），不计入总分
- improvements: {pre_shooting: [{aspect, suggestion}], post_processing: [...]}，各 1-3 条，参照「常见问题改进对照表」
- major_issues: 重大问题列表（字符串数组），每条一句话点明问题与原因；无重大问题则为空数组 []
- possible_issues: 首轮自评可能存在重大问题的方面列表（如「肤色」「皮肤质感」「曝光」），有不确定项时列出；确定无疑则为空数组 []；仅用于触发复核，不输出到点评
- texture_report: 皮肤质感结构化报告 {pore_visibility, texture_coverage, plastic_level}（取值见 rubric 第 0 节第 6 条），如实报告观察事实；磨皮问题不进重大问题，不输出到点评
- skin_report: 肤色结构化报告 {whiteness, exempt}（取值见 rubric 第 0 节第 1 条），如实报告观察事实；是否重大问题由系统规则判定，不输出到点评
- full_mark_endorsements: 复核轮对满分维度的显式背书 {维度名: 背书理由}；照片存在重大问题且其余维度满分时由系统校验，未背书自动降 0.5，不输出到点评
- prompt_suggestion: null（本板块不使用）

# 人物摄影评审标准

## 一、构图（3分）

### 1. 基础功（1分）

判断点：
- 横平竖直，明显水平线/垂直线不歪斜
- 背景干净简洁，头部不穿线，不杂乱
- 裁切避开关节：脖子、腰、膝盖、手腕等

扣分项：
- 背景杂乱、元素穿头
- 明显歪斜
- 关节处裁切不当

### 2. 视角与焦段（1分）

判断点：
- 视角有变化，避免普通平视
- 仰视、俯视、低机位可增加张力
- 广角人脸尽量居中，避免贴边畸变
- 长焦/人眼焦段构图自由，人物可放三分线、趣味点
- 单张照片景别清晰明确，与视角、构图意图匹配

扣分项：
- 广角人脸贴边变形
- 平视无视角变化
- 景别选择混乱，表达意图不清

### 3. 层次与平衡（1分）

判断点：
- 有前景、中景、背景的层次
- 兴趣点明确，人物放在三分线/中心/对称位置合理
- 倾斜构图有相对平衡，不是无理由歪斜

扣分项：
- 画面平，无前景
- 兴趣点混乱
- 倾斜无支撑，画面散乱

## 二、光线（4分）

### 1. 光比与曝光（1.5分）

判断点：
- 光比合适，高光不过曝，阴影不死黑
- 阴影区域保留微弱光线
- 以人脸曝光为主
- 正常曝光后期空间最大

扣分项：
- 逆光大面积过曝
- 阴影死黑，无细节
- 人脸欠曝或过曝

### 2. 光位与立体感（1.5分）

判断点：
- 侧光：近镜是影子、远镜是光，显瘦
- 顺光：近镜是光、远镜是影子，显胖；但有斑驳光时好看
- 逆光：有发丝光/轮廓光，找遮挡，不直拍光源
- 顶光：抬头强化轮廓，光影方向自然从上往下
- 有眼神光；眼睛在光里，脸上有斑驳感更好

扣分项：
- 顺光把脸拍平、显胖
- 逆光无轮廓、无遮挡
- 顶光不抬头，鼻影倒冲
- 无眼神光，眼睛死黑

### 3. 光质与用光逻辑（1分）

判断点：
- 选景即选光，优先选好光位/窗光
- 窗光是巨型柔光箱，但要注意光比
- 斑驳光、遮挡、反光板使用合理
- 影子是模特的一部分，不要全部照亮
- 人造光：灯头架高、尽量离机引闪，面部不要打过多灯

扣分项：
- 光线平淡，无明暗层次
- 灯光影子乱，面部光影脏
- 机顶直打，人物像贴纸，无立体感

## 三、后期（3分）

### 1. 影调与色彩（1.5分）

判断点：
- 高光、阴影层次分明，不发灰
- 黑白模式下依旧好看，影调合格
- 肤色白润自然，橙色通道处理得当
- 有黑白对比、冷暖对比、分离层次

扣分项：
- 强拉阴影导致发灰
- 肤色蜡黄、惨白或脏
- 色彩平淡，主体无法从背景中剥离

### 2. 液化与质感（1分）

判断点：
- 液化是微调：眼型、眼神光、脸型中庭/眼位/下庭
- 保留皮肤质感，不塑料磨皮
- 不盲目放大眼睛，不换脸

扣分项：
- 磨皮过度，皮肤塑料感
- 液化失真，五官比例失衡
- 盲目追求"锥子脸""大眼"

### 3. 统一与二次构图（0.5分）

判断点：
- 画面色调统一，无局部突兀
- 二次构图裁切/扩展补救有效
- 颗粒/胶片质感适度，顺光不加颗粒

扣分项：
- 色调不统一，画面局部色彩跳跃
- 颗粒过多，画面脏
- 二次构图无效，未补救前期构图缺陷

## 四、加分/前提项（不计入10分，单独点评）

这些内容不占评分，但会明显影响观感：
- 模特表现力：美或怪，或两者兼具
- 妆造：妆面是否定住，是否适合主题
- 道具/主题：是否主题先行，道具是否加分
- 生命力四要素：飞扬的发丝、灵动的姿态、不确定的瞬间、动态的道具
- 情绪与眼神：眼神是否灵动，有无眼神光，是否避免呆滞
- 引导细节：如"拿叶子看远方"，避免斗鸡眼

## 五、常见问题改进对照表

| 常见问题 | 前期拍摄建议 | 后期修图建议 |
| --- | --- | --- |
| 背景杂乱 | 换机位、用长焦、大光圈、低机位 | 裁切、二次构图、背景压暗/虚化 |
| 光比过大/逆光过曝 | 找遮挡、转侧逆光、用反光板、换拍摄时间 | 降低高光，提升阴影，保留层次 |
| 顺光显胖 | 转侧光/侧逆光，制造斑驳光 | 液化脸部，加强阴影立体感 |
| 广角畸变 | 人物放中间，换长焦或人眼焦段 | 透视矫正、二次构图 |
| 皮肤塑料感 | 正常曝光，不过度依赖后期 | 保留质感，降低磨皮强度 |
| 影调发灰 | 前期控制光比，阴影保留微弱光 | 黑白模式检查，调整曲线/色阶 |
| 色调不统一 | 固定色温，推荐5400K，统一光色 | LR/PS色彩平衡统一 |
| 缺少层次 | 加前景，控制光比，选光即选景 | 分离前景/主体/背景，拉开纵深 |
| 眼神呆滞 | 多沟通引导，拍低速连拍抓瞬间 | 后期加强眼神光，但不要凭空乱加 |

## 六、快速评分口诀

构图：横平竖直、广角居中、长焦自由、人眼三分、前景层次。
光线：顺光斑驳、逆光遮挡、侧光显瘦、顶光抬头、光比合适、人脸曝光。
后期：先定影调、再调肤色、液化微调、保留质感、黑白检查、统一色调。

## 输出

交互场景（Claude Code）：按上方「点评输出模板」逐段输出。

展示规则：点评各段落只写评语与扣分点，不写子项小分（如「基础功（1/1）」）；【评分】行不显示各部分的满分，只写分值本身与总分；直接输出模板，不加额外标题（如「摄影评审结果」）、不输出 route / 置信度等内部字段。

JSON 字段契约（API 服务器，由调用方 schema 强制）：
- total_score: 构图 + 光线 + 后期 之和（0-10）
- dimensions: 三项 [{dimension, score, comment}]——构图（满分3）、光线（满分4）、后期（满分3），满分仅用于内部计分；comment 只写评语与扣分点，不写子项小分
- bonus_notes: 加分/前提项观察（模特表现力、妆造、道具/主题、生命力、情绪眼神、引导细节），不计入总分
- improvements: {pre_shooting: [{aspect, suggestion}], post_processing: [...]}，各 1-3 条，参照「常见问题改进对照表」
- prompt_suggestion: null（本板块不使用）
只输出 JSON。

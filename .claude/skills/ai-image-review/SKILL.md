# AI 图片评审标准

## 1. 主体和主题是否突出（3分）

判断点：
- 主体明确，画面有清晰视觉焦点，观众第一眼知道看哪里
- 主题表达清晰，有明确情绪、故事、风格或概念
- 构图支持主体：位置、大小、对比、引导线等有效突出主体
- 画面简洁，背景不抢夺主体，无过多干扰元素

扣分项：
- 主体不明确，画面杂乱，不知道看哪里
- 主题模糊，元素无关联，表达混乱
- 构图失衡，主体被遮挡或边缘化
- 背景过于复杂，干扰主体
- 无叙事或表达，画面空洞

## 2. 特效和场景是否完美无瑕疵（4分）

判断点：
- 场景合理，透视、比例、空间关系正确
- 特效自然，与场景融合，无违和感
- 细节真实度高，无典型 AI 瑕疵：手部畸形、五官异常、乱码文字、重复纹理、边缘锯齿等
- 场景完整，背景、道具、服装等元素无断裂、缺失、不连贯
- 风格统一，无局部画风突变或色彩溢出

扣分项：
- 出现明显 AI 痕迹：手部异常、面部畸形、乱码文字、重复机械纹理等
- 特效与场景不融合，像贴图或合成失败
- 场景逻辑错误：透视混乱、比例失调、光影与场景不匹配
- 细节缺失或过度平滑：塑料感、模糊、无真实质感
- 风格不统一，局部元素突兀

## 3. 是否有光效和对比等突出内容（3分）

判断点：
- 光效合理，光源方向明确，光影逻辑自洽
- 光效氛围强：丁达尔、霓虹、逆光、体积光等增强画面氛围
- 对比突出：明暗对比、色彩对比、冷暖对比等增强视觉冲击力
- 层次丰富：高光、阴影过渡自然，有立体感，画面不发灰
- 光效与主题匹配，不突兀

扣分项：
- 光影逻辑混乱，光源方向不一致，阴影矛盾
- 光效平淡，无明暗层次，画面扁平
- 对比过度或不足：过曝/死黑，或发灰无对比
- 光效与主题不符，如温馨主题使用冷硬光效
- 色彩对比突兀，不协调

## 二、快速判断口诀

主体主题：主体明确，主题清晰，构图支持，画面简洁。
特效场景：场景合理，特效自然，无AI瑕疵，风格统一。
光效对比：光效合理，氛围突出，对比强烈，层次丰富。

## 输出

交互场景（Claude Code）：按上方「AI 图点评输出模板」逐段输出。

展示规则：点评各段落只写评语与扣分点，不写子项小分；【评分】行不显示各部分的满分，只写分值本身与总分；直接输出模板，不加额外标题（如「摄影评审结果」）、不输出 route / 置信度等内部字段。

JSON 字段契约（API 服务器，由调用方 schema 强制）：
- total_score: 主体主题 + 特效场景 + 光效对比 之和（0-10）
- dimensions: 三项 [{dimension, score, comment}]——主体和主题（满分3）、特效和场景（满分4）、光效和对比（满分3），满分仅用于内部计分；comment 只写评语与扣分点，不写子项小分
- prompt_suggestion: 只输出「提示词改进建议」部分：正向提示词与负面提示词必须是**完整可用、可直接粘贴给生图工具**的提示词文本（不是建议性描述），基于原图重新组织并纳入评审发现的问题；其他建议（参数/LoRA/重绘）为简短建议。不要包含【评分】和三个点评段落（那些在 dimensions.comment 中）
- improvements: {pre_shooting: [{aspect, suggestion}], post_processing: [{aspect, suggestion}]}，每组 1-3 条；aspect 用简短中文短语（如「提示词结构」「模型选择」「重绘修手」）
  - pre_shooting = 生成阶段建议（模型/采样参数/LoRA/提示词结构）
  - post_processing = 生成后精修建议（重绘/inpaint/局部修复/放大）
- bonus_notes: null（本板块无加分项）
只输出 JSON。

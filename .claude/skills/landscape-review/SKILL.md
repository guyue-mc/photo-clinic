# 风景摄影评审标准

## 一、构图（3分）

### 1. 基础功（1分）

判断点：
- 水平线、地平线横平竖直，不歪斜
- 画面边缘无杂乱干扰
- 透视自然，无意外畸变
- 裁切合理，不切掉关键元素

扣分项：
- 地平线、海平面明显歪斜
- 画面边缘出现树枝、杂物、路人干扰
- 建筑、树木有明显倾斜畸变
- 裁切不当，主体被切断

### 2. 视角与焦段（1分）

判断点：
- 视角选择明确：低机位、高机位、无人机视角、平视等
- 焦段使用合理：
  - 广角有前景冲击力
  - 长焦压缩层次，简洁画面
  - 标准焦段自然耐看
- 主体明确，兴趣点位置合理

扣分项：
- 视角平庸，无选择意识
- 广角拍风景无前景，画面空洞
- 长焦滥用导致画面过平、无空间感
- 主体不明确，观众不知道看哪里

### 3. 层次与空间（1分）

判断点：
- 有前景、中景、背景，层次分明
- 有引导线、框架、对称、留白等构图意识
- 空间纵深感强，画面不扁平
- 元素安排有节奏，不拥挤

扣分项：
- 画面扁平，无前景、无纵深
- 元素堆叠，杂乱无章
- 留白不足，画面拥挤压抑
- 构图手法生硬，为构图而构图

## 二、光线（4分）

### 1. 光比与曝光（1.5分）

判断点：
- 高光不过曝，阴影不死黑
- 大光比场景处理得当，如包围曝光、渐变镜、HDR
- 主体曝光准确，亮部暗部细节保留
- 光比控制自然，符合场景氛围

扣分项：
- 天空过曝死白，地面正常
- 阴影死黑，暗部无细节
- 大光比场景无处理，画面生硬
- 整体过曝或欠曝

### 2. 光位与时间（1.5分）

判断点：
- 光位合理：侧光、逆光、顺光、顶光选择符合场景
- 拍摄时间合适：日出、日落、蓝调、夜景等
- 光的方向能塑造立体感和质感
- 逆光有轮廓光、透光感；顺光色彩通透但不平淡

扣分项：
- 正午硬光拍摄，画面平淡、阴影生硬
- 光位选择随意，主体无立体感
- 逆光无氛围，只有死黑或过曝
- 顺光画面过于平淡，无光影变化

### 3. 光质与氛围（1分）

判断点：
- 光质软硬合适：
  - 早晚光线柔和
  - 阴天散射光均匀
  - 正午硬光少用
- 有光影对比、丁达尔、霞光、雾气等氛围
- 天气现象利用到位，氛围感强

扣分项：
- 光线过硬，画面干涩
- 无光影变化，画面像平涂
- 天气阴沉但没利用好氛围
- 光线杂乱，无方向性

## 三、后期（3分）

### 1. 影调与色彩（1.5分）

判断点：
- 明暗层次丰富，黑白灰过渡自然，不发灰
- 色彩自然或风格化统一，不跳脱
- 白平衡准确，或创意白平衡合理
- 冷暖对比、色彩分离合理，不过度饱和

扣分项：
- 强拉阴影导致发灰
- 饱和度溢出，色彩艳俗
- 白平衡偏色，色彩脏
- 局部色彩突兀，不统一

### 2. 细节与质感（1分）

判断点：
- 细节清晰，锐化适度
- 无过度锐化产生的白边、噪点
- 降噪合理，长曝光/高ISO画质良好
- 画面干净，无明显污点、杂物

扣分项：
- 锐化过度，画面生硬
- 噪点明显，画质粗糙
- 细节模糊，尤其是主体
- 画面有污点、灰尘、杂物未处理

### 3. 二次构图与畸变校正（0.5分）

判断点：
- 二次构图有效改善画面，裁切合理
- 透视畸变、镜头畸变已校正
- 全景接片、景深合成、HDR融合无明显痕迹

扣分项：
- 裁剪不当，破坏原构图
- 建筑、树木倾斜未校正
- HDR合成痕迹明显，画面发灰
- 接片有明显接缝或伪影

## 四、加分/前提项（不计入10分，单独点评）

这些内容不占评分，但会明显影响观感：
- 天气现象：云海、霞光、彩虹、闪电、星空、晨雾等
- 动态元素：水流拉丝、云层流动、星轨、飞鸟等
- 独特视角：无人机视角、超低角度、超长焦压缩、垂直俯拍等
- 叙事性：画面有故事感、情绪或意境
- 技术难度：长曝光、夜景、星空、全景接片、景深合成等

## 五、常见问题改进对照表

| 常见问题 | 前期拍摄建议 | 后期修图建议 |
| --- | --- | --- |
| 地平线歪斜 | 使用水平仪/网格线，三脚架校准 | 旋转裁切校正 |
| 高光过曝/阴影死黑 | 包围曝光，GND渐变镜，选对时间 | HDR合成，高光/阴影恢复 |
| 画面平淡无层次 | 寻找前景，利用引导线，选择侧光 | 分离层次，增加对比，局部提亮压暗 |
| 正午硬光拍摄 | 换时间，使用ND/CPL，找遮挡 | 调整高光阴影，降低对比，统一色调 |
| 色彩平淡/脏 | 选择黄金时段，准确白平衡 | 分区调色，色彩平衡，统一氛围 |
| 噪点严重 | 低ISO，三脚架，长曝光降噪 | 降噪，但保留细节 |
| 广角畸变 | 水平拍摄，使用移轴或矫正 | 镜头校正，透视变换 |
| 杂物干扰 | 前期避开，换机位 | 内容识别填充，裁剪 |
| 天空无细节 | 使用GND/包围曝光，等合适天气 | 高光恢复，替换天空或局部调整 |
| 接片痕迹明显 | 使用全景云台，保证重叠率 | 重新接片，修复接缝伪影 |

## 六、快速评分口诀

构图：水平对齐，主体明确，前中后景，引导线，留白合理。
光线：光比合适，时机选对，光位塑形，光质氛围，细节保留。
后期：影调丰富，色彩统一，细节质感，畸变校正，无合成痕。

## 八、经典色调建议库（可选，不计入评分）

只在照片适合时，作为"后期改进建议"的补充推荐，不强制使用。

| 色调 | 特点 | 适合场景 |
| --- | --- | --- |
| 紫金色调 | 高光偏金、阴影偏紫蓝，冷暖对比强，华丽感 | 城市夜景、蓝调时刻、日落余晖、灯光密集场景 |
| 黑金色调 | 只保留金色/橙色，其余色彩低饱和，暗部冷黑，高级安静 | 城市夜景、建筑结构、灯光密集、街景 |
| 青橙色调 | 阴影青蓝、高光橙黄，电影感强，明暗对比突出 | 城市风光、街景、日落、逆光山景、有明确光影的场景 |
| 蓝调时刻 | 天空蓝、灯光暖，冷色主导、暖色点缀 | 日落后20-30分钟，城市、海边、桥梁 |
| 暗调森林/墨绿金 | 低饱和绿、中低明度、静谧氛围 | 森林、雨林、晨雾、山谷 |
| 日系清透 | 低对比、高明度、青蓝绿+白，干净通透 | 海边、公路、花田、晴天顺光 |

使用方式：
- 如果照片是夜景灯光、蓝调时刻，可以在后期建议里加一句："可尝试黑金/紫金色调，统一画面色彩，突出灯光氛围。"
- 如果照片是城市街景、有明暗对比，可以建议："可尝试青橙色调，强化冷暖对比，增加电影感。"

## 输出

交互场景（Claude Code）：按上方「点评输出模板」逐段输出。

展示规则：点评各段落只写评语与扣分点，不写子项小分（如「基础功（1/1）」）；【评分】行不显示各部分的满分，只写分值本身与总分；直接输出模板，不加额外标题（如「摄影评审结果」）、不输出 route / 置信度等内部字段。

JSON 字段契约（API 服务器，由调用方 schema 强制）：
- total_score: 构图 + 光线 + 后期 之和（0-10）
- dimensions: 三项 [{dimension, score, comment}]——构图（满分3）、光线（满分4）、后期（满分3），满分仅用于内部计分；comment 只写评语与扣分点，不写子项小分
- bonus_notes: 加分/前提项观察（天气现象、动态元素、独特视角、叙事性、技术难度），不计入总分
- improvements: {pre_shooting: [{aspect, suggestion}], post_processing: [...]}，各 1-3 条，参照「常见问题改进对照表」；色调建议库仅在适合时作为 post_processing 的补充条目
- prompt_suggestion: null（本板块不使用）
只输出 JSON。
